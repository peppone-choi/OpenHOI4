상태: M0 운영 규약 확정. 기획 결정의 상태를 바꾸는 문서는 아니다. 기준: 01 §7, AGENTS.md §2, REQ-LEG-01·REQ-LEG-02·REQ-LEG-05. 작성일: 2026-10-06.

## 구현·콘텐츠 작성 전

- [ ] 작업의 REQ/WP와 허용 출처를 확인했다.
- [ ] 원작 파일·스크립트·현지화·이미지·음원·프로빈스 지도와 트레이싱을 입력이나 참고 자료로 열지 않았다.
- [ ] 원작 수치표와 위키 문장을 가져오지 않았다. 공개 역사적 사실은 자체 문장으로 작성하고 출처·확인일을 기록한다.
- [ ] 원작 의제·이벤트의 명칭·선택·배열을 복제하지 않는다. 원작 시스템의 비교 설명은 구조 수준으로 제한한다.
- [ ] 미결정 게임 규칙은 구현하지 않고 결정 요청 또는 작업 로그에 적는다.

## 데이터·에셋 추가 시

- [ ] 새 수치의 출처 또는 “밸런스 잠정” 근거를 팩 SOURCES.md에 기록했다. 게임 계수는 defines.toml에 둔다.
- [ ] 배포 데이터·에셋의 경로, 제작자, 원천 URL, 라이선스, 수정 여부, AI 생성 여부를 assets/ASSETS.toml에 등록했다.
- [ ] 직접 제작 자료는 원천을 original로 기록하되 미결정 D-10을 공개 라이선스 확정으로 취급하지 않는다.
- [ ] 외부 자료는 02 §14.3 허용 목록을 충족한다. 저작권 및 라이선스 정보는 원천 페이지에서 확인한다.
- [ ] 지도는 Natural Earth·OpenHistoricalMap의 허용 자료에서 자체 생성한다. CShapes를 사용하지 않으며 historical-basemaps를 D-10 확정 전 배포에 넣지 않는다.
- [ ] 위헌 단체 상징을 사용하지 않는다. 역사 국기는 자체 대체 디자인을 쓴다.
- [ ] AI 생성 임시 자료는 ai_generated=true로 표시하고 릴리스에서 제외한다. OPEN-09를 임의 확정하지 않는다.
- [ ] 화면 문자열은 ko·en 키로 관리한다.
