# 기능 백로그 (구현 단위)

- 작성: 2026-11-06, 기준 main `6c20c5c`
- 원본: WP 정의·선행 관계는 02 §12.2, 규칙은 01. 이 문서는 WP를 **PR 1개 크기의 구현 단위**로 쪼갠 실행 목록만 가진다. 규칙·수치를 새로 정하지 않는다.
- 상태 근거: main 병합 이력과 코드·wire·UI 존재 확인. 이번 작성에서 테스트·CI를 다시 실행하지 않았다. 동작 수준은 `미검증`이다.
- 범례: ✅ main 병합 · 🟡 일부 · ⬜ 미착수 · ⛔ 착수 전 사용자 결정 필요

**구현 단위 규칙.** 한 단위 = PR 하나. 데이터 → 시뮬레이션 → 저장/wire → UI → 검사 중 **사용자가 화면이나 CLI에서 확인할 수 있는 결과 하나**까지 끝낸다. 소비자(consumer)가 없는 내부 계산만으로 단위를 닫지 않는다.

**세분화 깊이.** M2 잔여는 바로 착수할 수 있는 크기로, M3는 WP당 3~6단위로, M4~M6은 WP 단위로 둔다. 먼 단위는 착수 시점의 실제 코드 계약을 보고 쪼갠다.
