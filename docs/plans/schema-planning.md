# 시스템별 스키마 기획

2026-10-06 사용자 지시를 반영한다. 이후 신규 시스템·스키마 변경 전에 담당 WP가 설계와 누락 대조를 남긴다. 진행 중인 WP-08은 남은 지도 HTTP·인덱스·조회 계약부터 적용한다. M1 기초 모델은 최종 전체 모델이 아니며 기존 독립 PASS를 새 기준으로 소급 취소하지 않는다.

설계는 `docs/plans/WP-NN-schema.md` 또는 해당 WP ADR에 둔다. 구현·검증 프롬프트가 정확한 문서와 검사할 불변성을 지정한다. 별도 전역 하네스·자동 반복·강제 리뷰를 활성화하는 지시가 아니다.

## 필드와 권위

필드별로 아래 내용을 기록한다. 컬렉션은 요소·키·정렬·중복 정책까지 적는다. ID와 배열 순번, 레지스트리 ID와 현지화 키, 초기 인구와 가용 인력, 주와 프로빈스, 소유와 통제를 같은 필드로 취급하지 않는다.

| 필드 | 의미·단위·정밀도 | 타입·실효 범위 | 필수/선택/null·기본값 | 참조·수명 | 기준 데이터·변경 권한 | REQ·WP·구현 상태 |
|---|---|---|---|---|---|---|
| 실제 경로별 작성 | 게임량/표시/기술량 구분 | 저장형뿐 아니라 파싱·계산·wire 제한 | 누락과 null 구분, 기본값 적용 위치 | ID 도메인·관계·생성/제거 | 단일 소유 시스템과 갱신 경로 | 현재 구현/후속/결정 필요 |

정의 데이터, 시나리오 초기값, 가변 권위 상태, 파생 원장·조회 DTO를 분리한다. 같은 개념을 여러 곳에 보관하면 기준값과 캐시의 관계·무효화·일치 검사를 명시한다. 이름만 비슷한 값이나 같은 정수 타입을 같은 의미로 쓰지 않는다. 위키의 필드 분류는 누락 조사 참고이며 OpenHOI4 게임 효과·수치는 01의 규칙과 채택 절차를 따른다.

## 관계와 검증 경계

참조 그래프에 다중성·안정 ID·정렬을 표시한다. 미존재/중복/삭제된 ID, 순환, 그룹 미소속/중복 소속의 허용·거부 정책을 관계별로 적는다. 인접 그래프의 순환과 기술 선행 그래프의 순환처럼 의미가 다른 관계를 일괄 금지하지 않는다. 전체 권위 모델과 필터된 조회 DTO도 구분한다.

데이터 파싱→구조 검증→참조 검증→상태 생성→명령/시스템 갱신→조회 순서에서 누가 무엇을 검증하는지 적는다. 실패 시 기존 상태·큐·캐시·파일이 보존되는 범위와 오류의 필드/파일/줄/열 또는 엔티티 문맥을 기록한다. 선언만 있고 실행 경로에 연결되지 않은 필드는 미완료다.

## 해시·저장·wire·화면

모든 가변 상태, 예약 큐, RNG, 보정치/만료의 canonical hash·저장·복원 포함 여부를 필드별로 대조한다. 불변 Defs와 pack identity, 파생값 재생성/실제 적용값 bit 일치, 표시용 시각·카메라 등 해시 제외값을 명시한다. 아직 없는 저장 기능은 계획으로 표시하며 DT를 통과했다고 쓰지 않는다.

파일/팩/HTTP/wire 버전과 구버전·미래 버전의 거부/마이그레이션·기본값 정책을 정한다. Rust 원본→생성 schema/TS→runtime shape 검사→실제 서버 조회→UI의 필드 의미·단위·null·현지화 참조가 일치해야 한다. schema annotation만으로 기본값 적용이나 변경 권한 검사가 수행됐다고 판단하지 않는다.

## 독립 예제와 누락 대조

정상·최소/최대·빈 값·누락/null·범위 초과·잘못된 참조·비연속 ID·관계 불일치·갱신 실패의 입력→거부/수락→전후 상태→출력 기대값을 설계에서 제시한다. 관련 저장 재개·호환·해시 변조·원장 bit·실제 UI 예제를 함께 연결한다. 검증자는 같은 구현의 기대값을 복사하는 대신 명세와 별도 기준 계산/fixture로 검사한다.

필드→REQ→WP 표로 현재 구현과 후속 마일스톤 누락을 대조한다. M1의 국가·주 기초 조회를 경제·정치·인력·군사 전체 모델 완료로 기록하지 않는다. 사용자 포함 확장은 [확장 목록](approved-extensions.md)과 최종 증거 대조에도 남긴다. 미승인 게임 규칙은 REQUEST, 승인 범위의 가역적 추천안은 04 §2의 잠정 채택 검토로 구분한다.

출처·열람 범위와 기술 참고는 [조사 기록](../research/schema-source-review.md)에 둔다. 원작 문장·수치표·파일·스크립트를 가져오지 않는다.
