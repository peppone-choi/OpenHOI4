# 사용자 확정 범위와 후속 구현 로드맵

2026-10-06 CEO가 전달한 사용자 항목별 답변을 반영했다. D-10 코드 GPL-3.0-or-later·직접 제작 데이터/에셋 CC BY-SA 4.0, D-12 OpenHOI4 확정. 다른 잠정 D 상태는 유지한다. OPEN 항목은 포함/제외 방향 확정과 아직 없는 세부 규칙을 구분한다. 01 §9의 식별자와 기존 WP는 유지한다.

| 시점 | 사용자 승인 범위 | 추적과 다음 행동 |
|---|---|---|
| M3 | 검토된 AI 이미지 배포물 포함 허용(OPEN-09) | WP-01 후속 에셋 검사 수정·독립 검증, WP-39 개별 배포 검토. 출처·도구·이용 조건·검토 기록 없으면 거부 |
| M4 | 간소화 평화 회의(OPEN-02), 보급 차량 소모만(OPEN-03), 기상/계절 모두(OPEN-07), 점령 저항/준수와 첩보 모두(OPEN-08) | WP-42/44, REQUEST-0002/0003/0004 세부 규칙 검토. 철도 궤간 변환 제외 |

| M6 | 자가 호스팅·세션 코드 접속·계정 없음(OPEN-10), 업적만(OPEN-12) | WP-49/50, REQUEST-0005 업적 세부 검토. 아이언맨 제외 |

공식 시뮬레이션 규칙이 아직 없는 시스템은 수치·효과를 창작해 구현하지 않는다. 후속 REQUEST의 추천안은 후보 설계이며 CEO가 잠정 채택할 수 있는 가역적 설계 작업과 사용자에게 받아야 하는 구체 게임 규칙·운영/비용 결정을 분리한다. 아직 없는 게임 규칙을 코드에 먼저 넣지 않는다.

사용자가 포함을 지시한 확장은 후속 마일스톤 계획·검증에서 누락하지 않는다. 기존 후순위 REQ의 우선순위는 이번 기록만으로 임의 바꾸지 않았으며 포함 결정의 실제 완료 증거를 WP별 계획·게이트에서 대조한다. 신규 누락 추적은 REQ-GEN-07(기상/계절), REQ-NAT-08(첩보), REQ-MIL-11(장비 설계), REQ-MIL-12(특수 무기), REQ-GEN-08(업적)으로 추가했다.

제품 공개 명칭 확정은 상표 안전성에 대한 법적 검증 완료가 아니다. 공개 배포·태그·서비스 운영·비용·Codex 설정 변경은 이 범위 결정에 포함되지 않는다.
