# M0 프로토콜 메시지 점검 목록

기준: 02 §4.3. 작성일 2026-10-06. 이 문서는 WP-05 범위 확인용이며 새로운 게임 규칙을 정하지 않는다.

| 방향 | 메시지 | M0 확인 | 후속 범위 |
|---|---|---|---|
| C→S | Hello | 프로토콜 버전 검사 | 인증은 M6 |
| S→C | Welcome | 엔진/프로토콜 버전, 최소 팩 정보, 버전 거부 | 전체 게임 세션 관리 M6 |
| C→S | Create / Join | 타입 계약과 빈 시나리오 접속 | 로비·다인 세션 M6 |
| C→S | Command | Pause·SetSpeed와 클라이언트 순번 | 군사/경제 등 명령은 해당 WP |
| S→C | CommandResult | 수락·거부와 현지화 사유 | 국가 소유권 M6 |
| S→C | Snapshot | 날짜·일시정지·속도 표시 | 국가/부대 등 상태는 해당 WP |
| S→C | Delta | 정의 및 날짜/시간 상태 전달 계약 | 누락 복구·재접속 REQ-NET-03은 M2 |
| C↔S | Query / QueryResult | 타입 계약과 실제 지원 범위의 명확한 응답 | 수치 원장 WP-10 등 |
| S→C | Notice | 현지화 키 기반 알림 계약 | 이벤트·경고 후속 시스템 |

Rust oh_proto가 타입의 원천이다. TS 생성물은 client/src/proto에 두고 재생성 후 diff가 있으면 CI가 실패해야 한다. 타입의 존재와 메시지의 실제 작동 검증을 구분한다. 클라이언트는 상태 표시·명령 입력만 하며 날짜 진행, 속도 계수나 규칙을 계산하지 않는다.

직접 확인할 증거: Rust MessagePack 인코딩→TS 디코딩, 버전 불일치 거부, 명령 수락/거부, 일시정지·재개·속도, 서버 날짜 표시, 빌드한 클라이언트 정적 파일 제공, ts-rs 재생성 검사, Playwright 캡처 조건과 경로. 후속 범위의 미구현은 지원되지 않는 메시지/명령으로 명시하고 성공으로 응답하지 않는다.
