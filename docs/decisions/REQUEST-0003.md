# 결정 요청 REQUEST-0003 — OPEN-02 간소화 평화 회의 세부 규칙

| 항목 | 값 |
|---|---|

| 관련 식별자 | OPEN-02, REQ-DIP-08 |

| 막지 않는 WP (계속 진행 중) | M1·M2, 기존 M3 단순 강화 |

## 질문 (한 문장)

간소화 평화 회의의 허용 요구와 점수 배분·참가자·진행 방식을 어떻게 정할 것인가?

## 선택지

| 선택지 | 플레이 경험 | 구현 비용 | 위험 |
|---|---|---|---|
| A: 제한된 요구를 한 번에 제출·확정하는 후보안 | 반복 라운드와 조작을 줄임 | 작은 UI·명령 집합 | 경쟁 요구의 충돌·권한 세부 결정 필요 |
| B: 소수 라운드의 순차 제안 후보안 | 상대 요구를 보며 조정 | 차례·순번 UI 추가 | 대기와 반복 조작 증가 가능 |

## 추천안과 이유

A를 M4 전 구체 후보안으로 준비하되 영토·반환·괴뢰국 등 허용 요구, 참가 자격, 점수 계산/소모와 경쟁 요구 처리에 대한 사용자 검토를 받는다. 간소화 방향만으로 이 규칙을 확정하지 않는다. 원작의 복잡한 절차나 수치를 옮기지 않는다.

## 기본안으로 먼저 진행할 경우 되돌림 비용

기존 M3 단순 강화는 유지한다. 신규 평화 회의의 세부 규칙·수치를 아직 구현하지 않으므로 콘텐츠·저장 파일 변경은 없다.

## 사용자 답 (사용자 또는 사용자 답을 옮긴 메인 에이전트가 기록)

방향 확정: "2번이되, 평화회의는 좀 단순화. HOI4의 평화회의는 너무 복잡해." 이 요청의 세부 요구·점수·절차에는 답변 없음.
