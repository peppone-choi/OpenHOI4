## 질문 (한 문장)

기상·계절의 발생과 효과, 점령지 저항·준수 및 첩보의 제도·행동·효과·수치를 어떤 규칙으로 정할 것인가?

## 선택지

| 선택지 | 플레이 경험 | 구현 비용 | 위험 |
|---|---|---|---|
| A: 각 시스템의 최소 행동과 효과를 별도로 설계·검토 | 작은 규칙과 분명한 정보 표시 | 데이터·UI·AI 연결 순차 작성 | 별도 결정 검토 필요 |
| B: 기상·점령·첩보 연계 전체를 일괄 설계·검토 | 시스템 간 선택 폭 증가 | 데이터·효과 규칙 비용 증가 | 서로 의존하는 수치·밸런스 재작성 |

## 추천안과 이유

A. M4 착수 전 기상 유형·발생/계절 자료·효과 대상, 저항/준수의 변화·정책, 첩보 행동·자원·성공 판정·정보 노출을 독립 설계안으로 제시해 사용자 검토를 받는다. 범위 포함 결정만으로 수치·발생/효과 규칙을 만들지 않는다.

## 기본안으로 먼저 진행할 경우 되돌림 비용

인터페이스·문서 조사만 가능하다. 미정 규칙을 선행 구현하지 않아 콘텐츠·저장 파일의 되돌림을 피한다. M1은 계속 진행한다.

포함 확정: OPEN-07 "기상과 계절 모두 포함", OPEN-08 "저항·준수와 첩보 모두 포함". 이 요청의 세부 제도·효과·규칙·수치는 답변 없음.
