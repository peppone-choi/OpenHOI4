- E1: 자기 `target/evidence/WP-17/`의 원 명령로그·native capture·save·raw JSON. 증거 manifest는 마무리 검사 후 같은 경로에 생성한다.

- E3/E4/E5: 이번 UI/AI benchmark/repro 번들 범위가 아니다. `movement_fixture`는 host 테스트 입력 producer이며 실제 UI플레이로 쓰지 않는다. 외부 CLI validate/ai-bench/repro는 소유 밖/현재 명령 미존재로 실행하지 않았다.
- 공개 wire/client/현지화/source는 변경하지 않았다. server용 dist만 로컬 빌드했다. 따라서 새 runtime MessagePack 구조 검사 대상은 없다. 원 wire contract는 workspace regression에서 검사했다.
