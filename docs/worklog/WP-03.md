- `req_gen_02_values_change_with_data`: 다른 픽스처의 수치를 바꾸면 로드 값도 달라지는지 검사.

개발 중 수정 기록: unclosed-array 픽스처의 최초 예상 위치를 EOF로 적었지만, 공식 TOML 파서는 마지막 유효 토큰 끝(`manifest 5:12`, `defines 2:12`)을 오류 span으로 제공했다. 실제 파일을 확인하고 정확한 parser span을 기대 위치로 명시했다. 검사 항목과 정확한 위치 일치 조건을 유지했고, 게임 골든이나 기존 테스트를 변경하지 않았다. Windows 텍스트 쓰기로 CRLF가 중복된 새 Unicode 픽스처는 의도한 CRLF 바이트로 교정했다. 초기 Raw visitor는 TOML 날짜의 비공개 Serde map을 다루지 못해 구문 오류로 분류했으며, 최종 구현은 공개 `DeTable`/`DeValue` API를 사용해 이 문제와 부동소수점 중간 변환을 제거했다.

- E6: 독립 검증 미실행. 구현 세션은 PASS 판정이나 완료 판정을 하지 않는다.

## 범위 밖 발견

- `oh_cli/src/main.rs`는 아직 빈 main이다. `oh run`, `oh validate`가 실제 구현되지 않았으므로 실행하거나 성공 증거로 기록하지 않았다. `oh run`은 WP-04, 전체 팩·참조/현지화 검증은 WP-24에 남긴다.
- 시뮬레이션·상태 해시와 세 OS 결정론 검사는 후속 WP 범위다. `oh_core`의 WP-02 변경을 가져오거나 수정하지 않았다.
- 최소 Testland의 현지화·지도·국가·시나리오 등 콘텐츠는 WP-23 등의 후속 범위다. 스키마와 실패 픽스처를 배포 자료로 옮기거나 에셋 검사 예외를 만들지 않았다.

## 못 한 부분과 이유

- 결정론 CLI 해시 2회: 실행 가능한 시뮬레이션/CLI 명령이 아직 없으므로 미실행. 동일 팩 로드 2회의 값 일치는 별도 테스트로 확인했다.
- CLI `oh validate`: WP-24 범위이며 명령이 없으므로 미실행. 파일 기반 로더 오류 픽스처로 M0 로더 검증을 실행했다.
- npm·TS 생성·Playwright: 클라이언트/프로토콜/UI를 수정하지 않아 적용 대상 없음.
- 독립 검증·main CI: 구현 세션의 권한 밖이며 오케스트레이터가 이 커밋을 대상으로 실행해야 한다.

## 수정 기록 (P-06)

- Git diff --check에서 원문 CRLF 픽스처의 CR을 trailing whitespace로 보고했다(exit 2). Git 속성/검사 정책 변경 대신, 저장 픽스처는 LF로 두고 별도 테스트가 target 아래 실제 CRLF 파일을 생성·로드하도록 수정했다. 그래서 어느 OS checkout에서도 CRLF 검사가 유지되며 검사 우회가 없다. 최종 git diff --cached --check는 exit 0이며 출력 없음.
- 독립 검증 피드백에 대한 수정 없음. 최초 구현의 내부 디버깅 결과는 위 테스트 우선 기록에 남겼다.
