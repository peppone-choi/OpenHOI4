## 증거
- E1: 초기 RED와 중간 실패/재시도 원출력. 기본 M0 Active localization 실패를 우회하지 않고 새 세션 기본 national m1을 사용했다. 내부 태그 unit variant가 unknown field를 무시하던 오류를 빈 struct variant로 고쳤다. 원 기존 target 보존 테스트가 이 문제를 잡았다.
- E2: 실제 stdin Host가 EOF 전에 event를 flush하고, EOF 뒤 ZIP에 시작 저장과 새 입력순서·실제 결과·종료 report를 담는다. fresh native replay가 종료 DTO/canonical/hash를 대조한다. snapshot pending은 한 번만 복원한다. 의미오류 소비와 wholephase ClockOverflow rollback을 구분하고 pause rescue의 동일 큐를 확인했다.
- E2 경계: paused 같은 tick의 여러 pump, 기존 예약 이동/Stop의 v2, v3 해협 진행/도착, v4 flags·effect/end checkpoint·ended step/enqueue 거부·미래5명령 보존·empty/initial/paused_condition을 실제 codec/CLI/별도 producer process로 대조했다. fixtures는 명시적 synthetic context이며 실제 CLI record 기능의 유일 입력원이 아니다.
- E2 ZIP: absolute/drive/UNC/../backslash/NUL/case/정규화 alias/중복/unknown/missing, ZIP member symlink/reparse, 실제 Windows junction input/output, CRC/잘림/중앙·local 길이/offset/flags/method/extra/선언 상한/압축 bomb, schema/seed/context/참조·log·fullDTO/canonical/한 비트 hash 변조를 거부했다. ZIP은 추출하지 않는다. compressed ZIP은 명확히 거부하고 start.ohsave의 bounded zstd는 보존한다.
- E2 I/O: 기존 output/inputsave/pack SHA·bytes 보존, 실제 tempfile prefix17bytes write 후 주입 I/O 실패의 native Rust 검사, Windows exclusive handle 때문에 실제 sync된 tempfile persist가 실패하는 native CLI 검사와 cleanup을 확인했다. Windows directory sync durability는 이 결과로 확정하지 않는다.
- E3: 사전 고정 prior 실제 라이브러리를 별도 read-only archive source로 빌드했다. build/download/pack load/warmup은 elapsed 밖이다. 각 source의 lock registry version/checksum을 감사하고 compiler/profile/features/pack 파일 bytes/SHA·seed/work량·native elapsed·실제 종료 tick/DTO/canonical/hash와 원 환경을 보존한다. 측정missing/0/비유한/실행실패는 오류다.
- 최종 인수 도구 `python -X utf8 tools/wp25_evidence.py`: committed source 변경파일 raw snapshot/길이/SHA, 전체 tracked 목록/각SHA·Git HEAD/status/index/diff, 원 실행증거를 SHA256SUMS.json과 evidence.zip에 보존하고 모든 member의 raw bytes/SHA/CRC를 재대조한다. ### None/v1 지원범위 인수
`--load`는 실제 bounded header.definitions_hash 유무로 host context kind를 결정하고, Active 검증 뒤 SaveContext::m0/false decode를 사용한다. replay 역시 bundle.national=false·pack/context/start identity를 검증한다. 유효한 Active M0/None 저장 자체를 거부하는 인터페이스가 아니다. 표준 예제의 원 testland_name 현지화 오류/CLI-only historical caller 제한과 구분한다.

- 새 evidence tool --out은 별도 namespace만 포장하고 기존 default root를 유지한다. 새 출력에는 P03 prior 전체를 자동 재편입하지 않는다. old manifests/index 원 길이/SHA 및 전체ZIP 링크는 P03-PRESERVED-LINKS.json으로 연결한다. 최종 새 source 변경 raw snapshot/전체 tracked SHA/Git 상태 및 whole/review 선택 차이는 새 ZIP-IDENTITY/REVIEW-SELECTION으로 인수한다. 새 approximately2GB baseline tar 원 stdout은 whole/raw에 남기고 review에서만 명시적으로 제외한다.
