### 환경 준비

- `vswhere -requires Microsoft.VisualStudio.Component.VC.Tools.x86.x64`가 기존 VS 2022 BuildTools·VS 2026 Community를 반환했다. MSVC 추가 설치는 하지 않았다.
- 공식 rustup-init x64 MSVC를 이 worktree의 `.orchestrator/evidence/WP-01/`로 다운로드하여 `-y --profile minimal --default-toolchain 1.99.0 --component rustfmt --component clippy --no-modify-path` 실행, exit 0. 출력: `1.99.0-x86_64-pc-windows-msvc installed - rustc 1.99.0 (b940084d7 2026-09-28)`.
- 사용자 `.cargo/bin`에 Rust를 설치했고 검증 명령에서만 프로세스 PATH에 추가했다. 글로벌 PATH·샌드박스·승인·네트워크 설정은 변경하지 않았다.
- `cargo install cargo-deny --version 0.20.2 --locked`, exit 0. 기존 MSVC로 빌드해 설치했다. `npx --prefix client playwright install chromium firefox webkit`, exit 0. actionlint 공식 Windows 배포 파일을 worktree의 제외 디렉터리에 풀어 문법 검사를 실행했다.

### 로컬 실행 방법

Rust 설치 후 `.cargo/bin`이 PATH에 있는 셸에서 `cargo build --workspace`, `cargo test --workspace`를 실행한다. 웹 골격은 `npm --prefix client ci`, `npm --prefix client run dev`로 연다. 테스트는 `npm --prefix client test`, `npm --prefix client run typecheck`, `npm --prefix client run build`다. 브라우저 smoke는 Playwright 설치 후 `npm --prefix client run test:e2e`로 실행한다. 현재 빈 셸에는 게임 화면·서버 연결이 없으며 Rust 실행 파일에도 지원 명령이 없다.

### 오케스트레이터 통합 진행

새 독립 검증 채팅에서 PASS를 받았으며 종료 후 HEAD·index·추적 파일 diff/status 무변경을 확인했다. main에 충돌 없이 병합하고 cargo test --workspace, npm ci, npm test, check_docs.py --write-trace를 직접 실행해 exit 0을 확인했다. 현재 CLI run/validate/상태 해시와 프로토콜 타입은 후속 WP로 미구현이므로 P-07의 해당 명령은 미실행으로 기록한다. 원격 branch CI 37434753777에서 3 OS 서버·클라이언트·에셋·문서 작업은 통과했으며, main CI 성공 후 이 WP의 통합 완료를 판정한다.
