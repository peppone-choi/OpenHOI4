- 저장은 자체 데이터 주도 권위 상태·명령 큐·고정소수점 rawbits·원장을 canonical hash와 검증하는 기술 경계다. 원작 포맷/스크립트/데이터를 참고하지 않았다. 제품 구현 전이므로 01 시스템 차별화 완료 행을 추가하지 않았다.

## 범위 밖 발견

- 위 read-only oh_data registry 반환 경계가 예정 소유 밖이다. 수정하지 않고 추가 배정 필요로 보고한다.
- 기존 server pack_hash의 디렉터리별 DFS/to_string_lossy는 임의 파일명에서 전체 상대 UTF-8 경로 정렬과 다르다. 예정 server 최소 저장 연결 내 공통 helper 사용·역전 fixture를 계획했다. 현재 제품 변경은 없다.
- 현재 time queue NationId는 실제 국가 참조가 아니다(server0, M1 nations1/2). future 국가 대상 명령의 참조 검사를 현재 Pause/Speed에 소급하지 않는다.

## 못 한 부분과 이유

- 제품 구현/red→green/cargo/저장 재개/3OS·독립 검증·main CI는 후속 구현 지시 전이라 수행하지 않았다.
- persistent RNG cursor·M3 autosave/upload/download·실제 live save UI는 현재 없거나 후속 범위다. 구현됐다고 기록하지 않는다.
