## P-03 제품 구현 기록 (2026-10-07)

부모가 90ebf63을 읽고 후속 구현을 배정했다. 추가 소유는 oh_data/map.rs의 기존 검증 resource/building registry read-only 반환과 관련 tests이며 구현했다. 자기 worktree에서만 명령을 실행했고 다른 채팅 생성/main 병합/환경 권한·검사 완화는 하지 않았다.

### 실제 변경 경계

- oh_sim/save_state DTO와 private export/from_save; 모든 시간/config/예약큐/ID참조/지지율/수량/원장 rawbit 검증 후 전체 candidate 반환. World/Simulation 기존 Serialize와 M0 hash는 그대로다.
- oh_save: OHSV v1 bounded header/body·allocation-free preflight→typed decode→정규 재encode 대조, single zstd frame/window/팽창/잔여 검사, pack/defs/typed defines identity와 제한된 force, timestamp·player metadata, atomic tempfile 교체와 cleanup/durability 진단.

### 제한·범위 밖·미수행

- invalid pending SetSpeed(0/6)가 있는 순간은 export/save InvalidQueue로 실패한다. live queue/hash/file을 보존하고 executor가 기존 InvalidSpeed rejection을 처리한 뒤 다시 저장할 수 있다. 모든 가능한 live 순간의 checkpoint 지원이라고 주장하지 않는다.
- Time queue의 NationId는 정렬 namespace이다. M0 None/M1 Some 모두 host0·미존재 nation 정렬 키를 유효하게 보존하고 국가 owner/controller 참조와 구분한다.
- government/support의 현지화 키는 기존 M1의 nonempty/ratio 계약을 검사한다. 존재하지 않는 정치 registry/새 효과를 구현하지 않았다. resource/building은 기존 실제 registry를 검사한다.
- 원자적 교체는 완전 old/new 파일·commit 전 오류 보존이다. Windows 공유잠금, partial writer failure, Unix 불가 쓰기 경로, 첫 저장/교체를 테스트한다. 모든 OS 전원손실·특수 filesystem durability를 보장하지 않는다. flush/sync 자체 OS 고장 강제는 별도 미실행이며 write/commit 경로와 오류 전파를 소스 대조한다.
- live browser save 버튼/HTTP upload/download/autosave·persistent RNG cursor는 현재 범위에 없다. actual native server wire Query/served JS identity를 실제 GUI 플레이로 부르지 않는다.
- 사용자 신규 게임 결정 필요 없음. formal 독립 P-05와 main 통합/CI/M1 gate는 부모 담당이며 아직 이 구현 세션의 판정이 아니다.
- 신규 source branch push 및 저장 전용 3OS workflow 실행은 후속 배정에서 허용됐다. 기존 일반 client CI의 WP08 DPR 문제는 소유 밖이며 수정/검사 완화하지 않는다.
