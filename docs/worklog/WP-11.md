### a7e6be1 실행과 경로 identity 추가 점검

a7e6be1의 clean Windows native 재실행·서버 조회 exit0을 `target/wp11-exact-a7e6/`에 보존했다. 서버 ownPID9368/port14536·정상 Ctrl+C 종료, exeSHA0bfde8fde3569e1a2b0d02921b6ccc0b3e0c68f8d033a7dcc500e6f9d17ae301·servedJS d3707b…a5de·pack b27b821484f4c43b다. checksum 손상 파일은 normal/force 모두 exit1 Compression 오류이고 old file SHA57b13c…22fa를 보존했다.
