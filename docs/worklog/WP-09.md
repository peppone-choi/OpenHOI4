## 공개 연결 계약 (WP-08 / WP-11)
- Rust API: `oh_data::national::load_scenario(pack_path,id)` → LoadedNational; `World::from_loaded(&loaded)`; `Simulation::with_world(...)`. `Simulation::world/config/pending_commands`, `snapshot`; `World::inputs/defs/definitions_hash`, nation/state/province typed 조회. mutable 필드와 Defs에 mutable 참조를 제공하지 않는다.
- Wire: 기존 `Query {request,kind}`. `world` 또는 `nation:<u16>`/`state:<u16>` → `WorldResult {request,supported,reason_key,world?}`. Join 전 not-joined, 없는 ID/invalid ID unknown-entity, M0 world 미지원 unsupported-query, 그 밖의 기존 query는 기존 QueryResult. entity query는 해당 nations/states Vec만 필터하며 map/province 메타는 전체다. App은 world 응답만 사용한다.
- `WorldView` tick/map_id/width/height/province_ids/neutral_color/mode_keys/nations/states/provinces. province_ids는 ID오름차순 dense index→ID이고 zero도 유효한 index다. Testland `[10,20,30,40,50,60]`, 8×6, 위쪽 원점 row-major WP-07 index를 사용한다. 실제 index binary HTTP는 WP-08 소유.
- ProvinceView는 state/owner/controller nullable과 각 owner/controller 색·terrain_key/terrain_color·state_color?를 제공한다. 무소유 색 대체는 server neutral_color. Mode keys는 map-mode-owner/control/terrain/state. 수치효과 없는 RGB 데이터로 모든 색을 제공하며 client가 임의 팔레트를 계산할 필요가 없다.
- StateView는 owner, 구성 province IDs, population/resources/buildings 문자열과 infrastructure `base/final_value/tick/entries`를 제공한다. entries는 Rust 순서의 id/label_key/operation_key/value/accumulated/source_key. client `ledgerProps`는 같은 문자열/순서를 LedgerValue props에 옮기고 `NationalPanels`는 optional nationId/stateId·선택 callback을 받는다.
- Fluent HTTP는 `/pack/localisation/en|ko/map.ftl|national.ftl`. 국가·정부·이념·주 키는 실제 pack에서 읽어 번들에 등록한다. UI 키는 기존 local catalog에 ko/en으로 등록했다.
- WP-11 재개 입력 전체: State의 scenario/seed/tick/date/hour/paused/speed; TimeConfig; `(tick,NationId,arrival sequence)`별 pending Command 전체; WorldInputs의 NationState(id/tag/government/support), StateState(id/owner/population/resources/buildings/base/modifiers/infrastructure/ledger), ProvinceState(id/state/owner/controller). modifiers의 inactive/expired 항목·source/target/op/value/expires도 보존해야 한다. 불변 Defs는 저장 제외, pack/definitions identity 확인 후 로드. ledger는 saved tick의 정확한 Fx 값으로 재생성/검증. 저장 DTO/Deserialize/재개 constructor는 WP-11에서 구현할 경계이며 이 WP는 public setters나 임시 save 구현을 만들지 않았다.
