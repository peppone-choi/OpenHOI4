## 못 한 부분과 이유
- Windows Playwright WebKit에서는 명시된 wght400 축/폰트 loaded 상태에도 글자가 다른 엔진보다 얇게 보인다. glyph 누락은 없고 언어·폰트 검사는 통과했다. 실제 Safari의 폰트 두께는 이 Windows 실행에서 검사하지 않았다.
- 실제 서버 국가/주 원장 연결·AC-M1-03 전체 판정은 WP-09/08 의존이 아직 통합되지 않았다. 아래 props로 연결할 수 있다.
- 독립 PASS·main 통합·동일 HEAD CI는 구현 세션의 권한/역할 밖이며 새 검증 세션/오케스트레이터가 처리한다. 이 로그는 완료 판정이 아니다.

공용 계약: `LedgerValue({labelKey,ledger:{base,final,tick?,entries:[{id,labelKey,operationKey,value,accumulated,sourceKey}]}})`. value/base/final/accumulated/tick은 서버 표시 string, entries는 readonly·서버 순서 유지. sourceKey는 Base 때 null, 나머지는 현지화 키. Base/Add/Mul operationKey는 ledger-base/ledger-add/ledger-multiply. 일반 표시 props이며 Rust wire 타입을 중복 정의하지 않는다. WP-09가 target_stat/tick/value/entries 결과를 변환한다. 클라이언트 숫자 변환·연산·반올림·정렬은 없다.
