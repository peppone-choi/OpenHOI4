### 필드·관계·저장 경계

schema와 ADR-1701/1702의 의미·단위·type/range·null/default·ref/lifetime/authority를 실제 소스와 대조했다.

- 불변 MapData/Defines, trusted 초기 UnitInput/context, 가변 위치·route·elapsed, 파생 경로 탐색을 구분한다.
- ID는 zero·비연속을 허용한다. speed는 양수 Fx km/h, route/progress는 hour, 계수는 양수 무차원 Fx다. missing을 1로 대체하지 않는다.
- unit→nation 및 position/allowed/correction/route→land/adjacency 참조, 순서·중복·kind를 생성/복원에서 검사한다. 지도 순환은 허용하며 최단 경로는 양수 cost와 전체 ID lexical 규칙을 따른다.
- movement None은 v1, movement Some/straits None은 v2, explicit straits Some은 빈 상태도 v3다. 신규 상태의 v1 export와 strait 상태의 v2 export는 손실 방지 오류다.
- 원 v1/v2의 지원을 유지하며 묵시 migration하지 않는다. v3는 동결 v2 base에 별도 context를 추가한다. bounded preflight 후 semantic·identity·hash 검사를 수행한다.
- 실제 unit/template 생성, 동적 infra/supply/access, public wire/server 조작 및 UI는 WP-16/14/19/20/22 후속이다. 함대·봉쇄·통행권·항구수송·진행중 allowed 변경 효과를 만들지 않았다.
