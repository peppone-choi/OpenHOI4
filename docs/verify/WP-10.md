테스트는 고정 기대값과 독립 i128 기준 계산을 포함한다. 원장과 공식이 같은 내부 경로를 쓴다는 사실만으로 통과시키는 자기 비교 테스트가 아니다.

별도 [독립 probe](E:/openhoi/.orchestrator/wt/WP-10-verify/target/verify/WP-10/probe/src/main.rs)는 제품의 정렬·산술 구현을 호출해 기대값을 만들지 않았다. Add/Mul별 BTreeMap과 i128 `div_euclid(2^32)`로 기대값을 계산했다.

- 경계값 19종의 **27,436개 조합**에서 모든 누적 비트와 정확한 overflow source/op 일치.
- Unicode source를 포함한 **120개 전체 입력 순열**의 정규 직렬화 바이트 일치.
- 만료 경계·최대 tick, target 격리, 빈값·중복, Add와 Mul의 동일 source 허용 검사 통과.
- 후속 상쇄·0 곱셈으로 중간 overflow를 숨기지 않는지 확인.
- 실제 적용값의 1bit 차이 거부, 입력 불변성, Modifier **114개 직렬화 왕복** 확인.
