# 선택적 작업 운영 지침

이 문서는 재사용 가능한 역할·운영 규약이다. 실행 이력, 채팅 기록, 인증정보는 공개하지 않는다. 2026-10-08 사용자 지시로 WP-14 인수부터 개발을 재개했다. 인계용 Git 반영 자체를 재개 승인으로 간주하지 않으며, 반복 감시 자동화는 재활성화하지 않았다. 현재 순서는 [M2 재개 계획](plans/M2.md)을 따른다.

## 0. 역할

사용자가 지정한 CEO는 오케스트레이터에게 작업 범위를 전달하고 결과를 확인한다. 오케스트레이터는 WP별 독립 worktree에서 구현 담당과 새 검증 담당을 분리한다. 제품 구현에 참여한 담당은 자신의 완료를 판정하지 않는다. 앱 turn 종료를 CLI exit=0으로 기록하지 않는다.

## 1. 실행 전 확인

현재 사용자 지시, HANDOFF.md, 원격 기본 브랜치와 로컬 WIP, 지정 worktree를 확인한다. 자동 반복·하네스·강제 위임을 전역으로 활성화하지 않는다. tools/orch.sh와 tools/ceo_run.sh는 선택적 실행 도구이며 이 파일을 읽는 것만으로 실행을 시작하지 않는다.

## 2. 결정과 권한

게임 규칙은 01 기획서의 확정·잠정 범위를 따른다. D·OPEN 상태 변경, 범위 확대, 복구하기 어려운 삭제, 설정·네트워크·권한 변경, 공개 배포와 비용 지출은 사용자 권한이다. 기술 잠정은 사용자 확정과 구분하며 기존 호환성을 깨는 승인으로 확대하지 않는다. 검증 실패나 도구 거절을 우회하지 않는다.

## 3. 기록과 종료

일반 설계·재현 명령·미완성 상태는 사람이 읽을 수 있는 문서로 남긴다. 비공개 실행 로그·raw API·비밀정보·증거 압축파일은 Git 공개 인계에 넣지 않는다. 결과는 실제 수행한 검사와 미실행 검사를 구분하고, 중단 지시가 있으면 새 작업을 시작하지 않는다.
