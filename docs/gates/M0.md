## 실행·캡처 조건

시나리오 이름은 `testland`, 실제 빈 팩은 `data/packs/examples/m0/testland`, manifest ID는 `m0_testland`다. 기존 `data/packs/testland` 로더 골격과 향후 완결 콘텐츠를 대체하지 않는다. 게임 계수·역사 수치를 가져오지 않았다.

독립 웹 검증은 실제 Rust 서버, 1280×720, en-US 브라우저 locale, 한국어/영어 UI를 사용했다. Chromium·Firefox·WebKit과 Windows 설치 Chrome·Edge를 실행했다. 캡처의 날짜·틱은 최고 속도 실행 및 촬영 시점에 따라 다르며, [브라우저 조건 JSON](../verify/evidence/WP-05/browser/)에 각각 기록했다. GPU 지도·게임 프레임 성능 증거로 사용하지 않는다.

클라이언트 빌드 후 Rust 서버를 빌드한다. 서버 실행 파일은 정적 클라이언트를 포함하고 데이터 팩은 별도로 읽는다. 다른 폴더에서 실행할 때는 `--pack-root`를 지정한다. Windows --open 시험은 실제 OS launcher의 exit 0을 확인했으며 브라우저의 시각적 탐색 성공까지 확인했다고 주장하지 않는다.

## 미완료와 이유

- 원래 `tools/orch.sh selftest`와 WP-00 CLI 호출은 모델/ChatGPT 인증 미지원 HTTP 400으로 실패했고 status는 done 1이었다. 사용자 승인 앱 실행으로 대체했으며 CLI 성공으로 바꾸어 기록하지 않는다.
- 지도·경제·전투·AI·저장/재개·재접속·멀티플레이는 후속 WP다. M0 스케줄러의 빈 슬롯을 실제 게임 동작으로 계산하지 않는다.
- 전체 데이터 validate·AI 대전·bench·repro는 WP-24·WP-25·AI WP의 후속 기능이다. 현재 지원되지 않으며 전체 REQ-GEN-06 목표 완료로 보고하지 않는다.
- Three.js WebGPU 우선·WebGL2 대체와 실제 GPU 지도/성능은 WP-08/M1이다. 기술 결정은 문서에 반영했고 M0 구현 증거에는 포함하지 않는다.
- 실제 Safari와 Opera·Brave·Whale 등 제품별 수동 검증은 아직 하지 않았다. 세 엔진 검증 및 Windows Chrome·Edge 시험과 구분한다.
- docs/, tools/, AGENTS.md 삭제는 사용자 지시에 따라 최종 게임 개발 완료(M6 이후)에 적용한다. 현재 M0 운영·검증 자료는 유지한다.
