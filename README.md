# OpenHOI4

OpenHOI4는 국가 하나를 맡아 산업, 외교, 연구, 군대를 운영하는 대전략 게임입니다. 세계의 모든 국가는 동시에 움직이며, 플레이어는 시간을 멈추고 계획을 세우거나 속도를 높여 전개를 지켜볼 수 있습니다.

1930~40년대 세계대전을 배경으로 한 기본 게임과, 시대·지도·국가·장비를 교체할 수 있는 데이터 중심 엔진을 함께 개발합니다. 브라우저에서 플레이하며, 로컬 서버가 게임을 진행합니다.

## 어떤 게임인가요?

- **평시의 준비가 전쟁으로 이어집니다.** 산업 역량을 생산과 건설에 배분하고, 장비를 비축하고, 사단을 편성합니다.
- **큰 방향과 직접 지휘를 함께 다룹니다.** 군에 전선과 공세 계획을 주거나 사단을 직접 이동시킵니다.
- **수치의 근거를 확인할 수 있습니다.** 생산량, 전투력, 보급량 등의 계산을 수치 원장으로 보여주는 것을 목표로 합니다.
- **역사 이후의 전개는 플레이어에게 달려 있습니다.** 역사적인 시작 조건에서 국가 의제와 외교로 다른 경로를 선택합니다.
- **새로운 시대와 세계를 만들 수 있습니다.** 기본 게임도 데이터 팩으로 구성하며, 같은 엔진에서 가상 세계나 다른 시대의 시나리오를 지원합니다.

## 개발 상태

현재는 기반 시스템을 개발하고 있습니다. 위의 게임 시스템이 모두 구현된 상태는 아닙니다.

첫 완결 시나리오는 가상 세계 **Testland**입니다. 이후 **유럽 1939** 시나리오를 첫 플레이 가능한 버전으로 만들고, 최종적으로 1936~1948년 전 세계와 멀티플레이를 지원하는 것이 계획입니다.

## 실행 환경

클라이언트는 데스크톱 웹 브라우저에서 실행하며 WebGL2를 사용합니다. 서버는 Windows, Linux, macOS를 대상으로 개발합니다. 싱글플레이도 로컬 서버와 브라우저로 실행하는 구조입니다.

## 독립 프로젝트

원작 게임의 설치나 파일을 사용하지 않는 독립 프로젝트입니다. 규칙과 콘텐츠는 자체적으로 설계하며, 공개 명칭과 배포 라이선스는 공개 전에 확정할 예정입니다.

이 프로젝트는 Paradox Interactive와 무관하며, 언급된 상표는 각 소유자의 것입니다.
