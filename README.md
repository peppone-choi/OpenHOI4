# OpenHOI 기획 산출물 세트

HOI 시리즈 구조를 계승한 오픈소스 대전략 게임 **OpenHOI**(코드네임)의 기획서·제작용 문서·제작용 프롬프트 한 세트입니다. 저장소 루트에 그대로 복사해서 쓰는 구조입니다.

> 이 프로젝트는 Paradox Interactive와 무관하며, 언급된 상표는 각 소유자의 것입니다.

## 구성

| 파일 | 내용 |

| [docs/02-production-spec.md](docs/02-production-spec.md) | **제작용 문서**: 확인된 기술 버전, 결정론 규칙, 서버·웹 클라이언트 아키텍처와 프로토콜, 데이터 규격, 저장·AI·모드·멀티플레이 설계, 작업 패키지 50개와 병렬 묶음, Codex 세션 운영, 테스트·CI, 완료 판정, 추적 매트릭스 |

## 제작 체계 (D-15, 확정)

모든 역할을 Codex가 맡습니다.

```
사용자 → 오케스트레이터 Codex 세션 (P-01 붙여넣기)
           ├─ tools/orch.sh start impl   → Codex 구현 세션 × 최대 3~4 (WP별 worktree, 병렬)
           ├─ tools/orch.sh start verify → Codex 검증 세션 (새 세션, 파일을 바꾸면 무효)
           └─ 그동안 오케스트레이터는 다음 프롬프트 작성·통합·문서 갱신
```

## 사용 순서

1. 새 git 저장소(비공개 권장, D-14)에 이 폴더 내용을 복사하고 커밋합니다.
2. 저장소에서 Codex를 시작하고 [03 P-01](docs/03-production-prompts.md#p-01-최초-착수) 본문을 붙여 넣습니다.
   - 오케스트레이터 세션 안에서 하위 `codex exec`가 API에 접속할 수 있어야 합니다.
   - P-01의 0단계 `tools/orch.sh selftest`가 이를 확인합니다.
3. M0가 끝나면 P-02에 `M1`을 넣어 이어갑니다.
4. 문서를 고친 뒤에는 `python3 tools/check_docs.py`를 실행합니다.
