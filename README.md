# OpenHOI4

OpenHOI4는 국가 하나를 맡아 산업, 외교, 연구, 군대를 운영하는 대전략 게임입니다. 세계의 모든 국가는 동시에 움직이며, 플레이어는 시간을 멈추고 계획을 세우거나 속도를 높여 전개를 지켜볼 수 있습니다.

1930~40년대 세계대전을 배경으로 한 기본 게임과, 시대·지도·국가·장비를 교체할 수 있는 데이터 중심 엔진을 함께 개발합니다. 브라우저에서 플레이하며, 로컬 서버가 게임을 진행합니다.

## 어떤 게임인가요?

- **평시의 준비가 전쟁으로 이어집니다.** 산업 역량을 생산과 건설에 배분하고, 장비를 비축하고, 사단을 편성합니다.
- **큰 방향과 직접 지휘를 함께 다룹니다.** 군에 전선과 공세 계획을 주거나 사단을 직접 이동시킵니다.
- **수치의 근거를 확인할 수 있습니다.** 생산량, 전투력, 보급량 등의 계산을 수치 원장으로 보여주는 것을 목표로 합니다.
- **역사 이후의 전개는 플레이어에게 달려 있습니다.** 역사적인 시작 조건에서 국가 의제와 외교로 다른 경로를 선택합니다.
- **새로운 시대와 세계를 만들 수 있습니다.** 기본 게임도 데이터 팩으로 구성하며, 같은 엔진에서 가상 세계나 다른 시대의 시나리오를 지원합니다.

## 개발 상태

현재는 게임의 기반과 국가·주 정보를 연결한 단계입니다. 합성 Testland의 국가·주 정보와 실제 인프라 수치 원장을 조회하고, 날짜·시간·일시정지·재개·5단계 속도를 조작할 수 있습니다. 한국어와 영어 화면을 제공합니다. 지도 렌더링·저장·경제·전투·AI는 개발 중이며, 아직 완결된 게임을 플레이할 수 있는 버전은 아닙니다.

첫 완결 시나리오는 가상 세계 **Testland**입니다. 이후 **유럽 1939** 시나리오를 첫 플레이 가능한 버전으로 만들고, 최종적으로 1936~1948년 전 세계와 멀티플레이를 지원하는 것이 계획입니다. 현재 기본 서버는 M1 검사용 최소 Testland를 로드합니다. 완결 콘텐츠와 기존 M0 빈 예제는 별도로 유지합니다.

## 실행 환경

서버는 Windows·Linux·macOS를 지원하고, 클라이언트는 데스크톱 웹 브라우저에서 실행합니다. 싱글플레이도 로컬 서버와 브라우저로 실행하는 구조입니다. 브라우저는 서버가 보낸 상태를 표시하며 게임을 자체 계산하지 않습니다.

웹 셸은 Chromium·Firefox·WebKit 엔진과 실제 Chrome·Edge에서 검사했습니다. Safari 실제품과 Opera·Brave·Whale 등은 추가 확인 대상입니다. 지도는 사용 가능한 GPU를 활용하는 Three.js의 WebGPU 우선·WebGL2 대체 경로로 개발할 예정입니다.

## 소스에서 실행

Rust 1.99.0과 Node.js 24 이상, 해당 OS의 빌드 도구가 필요합니다. 저장소 루트에서 클라이언트를 먼저 빌드한 뒤 서버를 실행합니다.

```sh
npm --prefix client ci
npm --prefix client run build
cargo run -p oh_server -- --open
```

서버가 출력하는 로컬 주소로 접속하면 됩니다. `--open`은 기본 브라우저를 열고, `--help`는 사용법을 표시합니다. 종료하려면 실행 터미널에서 Ctrl+C를 누릅니다.

빌드된 서버 실행 파일은 웹 클라이언트를 포함하므로 실행할 때 Node.js나 별도 웹 개발 서버가 필요하지 않습니다. 데이터 팩은 별도로 읽으며, 다른 폴더에서 실행할 때는 `--pack-root`로 팩 루트를 지정합니다.

M1 국가·주 상태를 화면 없이 실행하고 반복 해시를 확인할 수도 있습니다.

```sh
cargo run -p oh_cli -- run --pack data/packs/testland --scenario m1 --ticks 1000 --seed 1 --hash-out
```

기존 M0 빈 시나리오의 회귀 실행 경로도 유지합니다.

```sh
cargo run -p oh_cli -- run --scenario testland --ticks 1000 --seed 1 --hash-out
```

## 독립 프로젝트

원작 게임의 설치나 파일을 사용하지 않는 독립 프로젝트입니다. 규칙과 콘텐츠는 자체적으로 설계합니다. 공개 명칭은 OpenHOI4이며 코드는 GPL-3.0-or-later, 직접 제작 데이터와 에셋은 CC BY-SA 4.0입니다. 외부 자료는 각 원래 라이선스를 따릅니다. 이름 선택은 상표 안전성에 대한 법적 검증 완료를 뜻하지 않으며, 정식 배포는 별도 공개 게이트를 거칩니다.

이 프로젝트는 Paradox Interactive와 무관하며, 언급된 상표는 각 소유자의 것입니다.
